# Agent Workbench guides

These guides explain how to install Agent Workbench, pick a model and a coding agent for a project folder, set up what the agent reads, and fix what goes wrong.

- [Getting started](getting-started.md): what you need, how to install, the setup guide step by step, and three short routes to a running agent.
- [Model sources](model-sources.md): a model on this computer, a server that is already running, a GPU machine over SSH, hosted providers and agent accounts, and which agent can use which.
- [Project setup](project-setup.md): instruction files, skills, MCP servers, the consent step, starter kits, what is remembered for each folder and which settings travel with it.
- [Sessions and terminals](sessions.md): the terminal dock, agent windows, running and recent sessions, run summaries, remote sessions, Trace and the Docker sandbox.
- [Troubleshooting](troubleshooting.md): Doctor with one section per check, the messages you can meet when a model, an agent or a machine does not start, and how to uninstall.
- [Security and your data](security-and-data.md): what runs with your account, where Workbench keeps data and keys, and what it trusts.
- [Reference](reference.md): every command-line verb and flag, every environment variable, the engines and the ports.
