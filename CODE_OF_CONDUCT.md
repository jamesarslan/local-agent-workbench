# Code of conduct

Agent Workbench is a small project. This code keeps discussion about it technical and respectful, so that questions get answered and problems get fixed.

## Expected

- Be specific and kind.
- Criticise ideas and code, not people.
- Share detail others can reproduce: version, system, steps and output.
- Respect that the project is maintained by one person in spare time.

## Not acceptable

- Harassment or discrimination of any kind.
- Personal attacks, insults or deliberate provocation.
- Publishing someone's private information without their permission.
- Spam and promotion unrelated to the discussion.

## Where it applies

The repository's issues, pull requests, discussions and security advisories, and any other space where you speak for the project.

## Reporting

Use GitHub's "Report content" option on the comment or the profile. To reach the maintainer privately, use the private reporting form named in [SECURITY.md](SECURITY.md#reporting-a-vulnerability) and say that the report is about conduct.

## Enforcement

The maintainer may edit or remove comments, close threads and block accounts that break this code. The maintainer decides alone and does not have to give reasons in public.
